# Boba Bliss - Bootstrap 5 Website
เว็บไซต์ตัวอย่างชานมไข่มุก 4 หน้า: Home, About, Products, Contact

## วิธีเปิด
ดับเบิลคลิก `index.html` หรือเปิดด้วย Live Server ใน VS Code

## Bootstrap Components
Navbar, Hero, Carousel, Card, Button, Badge, Alert, Modal, Accordion, Form, Breadcrumb, Progress, Dropdown

## หมายเหตุ
รูปภาพตัวอย่างโหลดจาก Unsplash ผ่าน URL จึงต้องเชื่อมต่ออินเทอร์เน็ตขณะเปิดเว็บ
